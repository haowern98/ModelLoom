# Multi-desktop timeout audit, 21 October 2026

The user authorized correction of premature timeouts and stale loaded state during distributed inference. This audit covers the desktop/core request path, authenticated peer transport, native relay and owned cleanup. It does not change weights, sampling, context settings or output quality.

| Operation                                              | Previous limit                                            | Current behavior                                                                                                                                                |
| ------------------------------------------------------ | --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Loaded native RPC session without bytes                | 2 minutes                                                 | No idle expiry. Owner EOF, explicit stop and worker disconnect still end the session.                                                                           |
| Pending IPC fragment acknowledgement                   | 15 seconds                                                | 30 minutes. One 8 KiB fragment remains in flight; downstream backpressure counts toward this budget.                                                            |

| Loss of an admitted remote RPC transport               | Closed the transport, leaving coordinator ready           | Stops the affected retained coordinator job and confirms its exit. Normal stock enumeration closes and intentional owner shutdown do not report remote failure. |

The following shorter bounds remain intentional: authenticated management/status requests, RPC upgrade and worker startup, approval expiry, incomplete private frames, incoming HTTP headers/body uploads, stalled API readers, local status polling, and user cancellation. They govern admission, malformed/stalled clients, liveness or disposal, rather than healthy idle model lifetime. A five-second cancellation proof deadline remains separate from successful-stream disposal proof. The peer lease is refreshed by its separate heartbeat, not native RPC traffic.

Regression coverage includes six-minute generation and queue residence, token preparation past two minutes, IPC backpressure past fifteen seconds and eventual expiry, remote transport loss, ordinary enumeration closure, retained coordinator exit, delayed terminal disposal proof, and remote estimator completion past two minutes. The Windows native idle test keeps the worker idle for 125 seconds and then performs the real stock RPC handshake. It failed with the old native relay and passed with the corrected relay.

Automated tests and the native handshake do not establish a new full 27B generation run across both desktops. Record that live result separately.
